# 零售批发进销存系统

面向零售和批发业务的简体中文 Web 系统。可从采购订单生成采购入库单并付款，从报价单生成销售订单、销售出库单并收款。记账时同步写入库存、往来账、资金流水与会计分录。参考分析报告第 21 节确定范围。

## 本地运行

安装 Node.js 24 或更新版本。在项目目录执行以下命令，无需安装第三方依赖。

```sh
cd /Volumes/Untitled/gjp
ERP_DEMO=1 ERP_DB=./data/demo.sqlite npm start
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。演示账户为 `admin`，密码为 `Demo-Inventory-2026`。演示账套首次启动时生成两个仓库、三种商品、一个客户和一个供应商，以及已记账的样例采购、销售和资金单据。演示密码只用于样例账套。

首次创建独立空白账套时，在终端设置自己的管理员密码，再启动服务。下例适用于 zsh。

```zsh
read -rs 'ERP_ADMIN_PASSWORD?管理员密码（12–128 字符）: '
export ERP_ADMIN_PASSWORD
ERP_DB=./data/business.sqlite npm start
```

空白账套预置基础会计科目，登录后在资料中建立商品、仓库、往来单位和资金账户，在「期初建账」录入期初余额并开账，在职员管理中新增操作人员。首次启动后密码保存在数据库的加盐哈希中。后续启动同一账套时可省略 `ERP_ADMIN_PASSWORD`。

- `ERP_DB` 指定 SQLite 文件，默认为 `data/erp.sqlite`。账套通过不同文件隔离。管理员可在「系统 → 数据备份」下载 SQLite 快照。重建前自动备份，备份默认保存在账套文件旁的 `.backups` 目录（例如 `data/erp.sqlite.backups`）。如需核对或恢复备份，可复制快照并用 `ERP_DB` 指向该副本启动独立账套。
- `ERP_TIMEZONE` 指定服务器的记账日期时区，默认为 `America/New_York`。浏览器日期随设备时区显示。
- `PORT` 默认为 3000，`ERP_HOST` 默认为 `127.0.0.1`。多位职员通过同一服务地址使用同一个账套。
- 跨设备部署时，将服务放在 HTTPS 反向代理后，设置 `ERP_SECURE_COOKIE=1` 并保留请求的原始 Host。需要分享对账链接时，客户必须能访问该地址。
- 资料、单据和报表可导出Excel 工作簿（.xlsx）。导出记录进入系统日志。

## 开单和记账

1. 在商品信息中建立商品，录入计量单位、采购价与零售价。可在商品中设置换算，例如 `箱=12个`。
2. 录入采购订单，保存后在单据中心完成提交、审核和记账。随后可生成采购入库单。采购入库单记账时增加实物库存和应付。
3. 从已记账的入库单生成付款单，选择资金账户、核对金额并记账。
4. 依次办理报价、销售订单和销售出库。选商品时按价格本、数量阶梯价、预设售价、默认价取价。未命中采购价格层时使用商品采购价，如无采购价则使用零售价。
5. 出库记账后从销售出库单生成收款单。全额结清后可确认结算。即时收款、单独预收及按单收款分别留有流水。
6. 在库存状况查询可按仓库和商品分类筛选，选中上级分类时包含子分类，导出 Excel 使用同样的筛选条件。在经营报告选按日或按月，设置日期范围后点击「查询」。
7. 在单据详情使用「打印单据」。打印模板中心按单据标题关联抬头和页脚。商品条码使用 Code 39，适用字符为大写英文字母、数字及其支持的标点。

### 单据中心和权限

状态为草稿、待审核、已审核、已记账、已结算、截停、驳回、已删除。库存入库和出库单据在列表分别显示已入库和已出库。仅草稿和驳回单据可编辑。有「反审核」权限的职员可将已审核、未记账的单据退回草稿，再按权限编辑或删除。单据列表支持勾选后批量反审核或删除，整批状态或权限不符时回滚。记账后通过对应退货、换货或调整单据更正。编号首次保存时发放，格式为业务前缀、日期和五位流水号，例如 `XS-20261114-00001`，已编号后日期固定。出库和收款分别完成库存与资金动作，原单据的结算按钮核对剩余单据余额。

| 角色 | 操作 |
| --- | --- |
| 管理员 | 维护职员和系统资料，制单、审核、反审核、记账、结算、月结 |
| 制单员 | 维护一般业务资料、保存、提交、截停和软删除、恢复 |
| 审核员 | 审核、反审核、驳回、截停、记账和确认结算 |
| 只读职员 | 查询和导出授权范围内的数据 |

部门和仓库限制由服务端核对，空白部门单据为共享单据。未分配仓库表示可查询全部仓库。仓库限制用于库存快照和影响库存的单据，财务关联收付款继承原单据仓库和部门。未指定单据的结算流水保留在往来单位级别。商品目录及往来单位是共享资料。会话保存在服务端，浏览器使用 HttpOnly Cookie。

### 成本和会计口径

- 金额以分存储，库存以千分之一基本单位存储。采购单价经过折扣后计入不含税库存成本，行税额单独四舍五入。多单位数量在记账时转换为基本单位。
- 移动加权以商品和仓库为核算粒度，入库时合并存货金额，出库按当时的仓库成本扣减。
- 全月一次加权在月内暂用移动成本，月结时按期初金额加本月入库金额，除以同期可用库存数量，重算当月出库和期末库存。支持在期间间切换成本算法。同商品同仓同月混合算法、全月加权商品存在调拨或销售退换货、或同一商品同仓已经记账到后续期间时，月结会拒绝自动重算。待扩展为跨仓及跨期重算。盘点按实盘数量与账面数量的出入库差异记账。
- 销售出库借记应收、贷记销售和销项税，同时结转存货成本。采购入库借记存货与进项税、贷记应付。收付款借记和贷记对应现金银行及应收应付。费用、预收预付、转账、期初和存货差异各写入相应科目。手工会计凭证校验借贷平衡。月结的成本差额写入存货与对应损益分录。适用科目及报表口径应按企业会计规则核对。
- 应收应付分单位汇总，电话可作为精确查询条件。对账页面可生成指定单位和日期范围的只读流水快照。链接有效期七天，持有人可打开。应用内提供复制和预览。

## 技术栈与数据库

Node.js HTTP 和原生浏览器 JavaScript 负责接口和界面，SQLite 保存关系数据。选用该组合是为了在单机上直接运行、集中保存多用户数据，并让记账写入、状态转换和流水号分配处于同一数据库事务。

| 表 | 用途与关系 |
| --- | --- |
| `master` | 通用资料表，按类型和编号唯一。保留名称、状态和各类型扩展字段，例如商品、套餐、客户、供应商、仓库、账户、各价格层和打印模板。 |
| `users`, `sessions` | 职员、角色、部门及仓库范围。会话关联职员并记录有效期。 |
| `documents`, `lines`, `sequences` | 所有业务单据共用表头和明细。明细关联商品，表头关联仓库、往来单位和制单职员。流水号按业务和日期分配。 |
| `attachments` | 单据附件二进制内容，通过单据权限查询。 |
| `stock`, `movements` | 商品与仓库的当前数量和金额，以及记账后可追查到单据行的库存变化。 |
| `lots`, `serials` | 批次有效期、批次现存数量和序列号当前仓库。 |
| `ledger`, `journal_entries`, `closes` | 往来与资金子账、借贷会计分录和会计期间结存。 |
| `statement_links`, `audit` | 对账快照和令牌散列、操作及导出记录。 |

相较参考文档第 16 节的推测模型，本实现将业务单据统一到表头和明细，通过流水生成库存余额和财务报表。按单结算由流水上的原单据引用实现。待处理的销售、调拨订单占用从订单数量扣除已记账的关联处理量计算。可销售、可发货共用这套本地占用口径。两个仓库间实物调拨在同一事务扣增库存，在途统计以尚未完成的调拨订单为依据。套餐库存按组成件可用数量估算。

## 单据弹框与操作修订

- 单据的往来单位、仓库、商品、经手人、部门、账户、科目、物流公司和关联单据使用同一选择弹框。支持按编号、名称、已维护的拼音码搜索，商品也支持按条码搜索。结果每页 25 行。点击行后按「确定」，或双击行即可选中。按 Esc 或「取消」保留原值。采购和销售退货加载源单时暂时锁定编辑，按来源行替换明细，并校验剩余可退数量。商品单位自动带出，只有商品设置了多单位时才提供单位选项。经手人来自在职职员，部门来自职员资料中的部门。非管理员的部门选择遵循原有部门权限。
- 销售出库可选销售订单或报价单，销售订单可选报价单，采购入库可选采购订单。选定后用来源单据的商品明细替换当前明细，并带入适用的往来单位和仓库。已提交、已审核、已记账和已结算的订单及报价单可带入草稿。后续单据记账前，来源单据仍需先完成记账。提示会显示未记账的来源单据类型、单号和打开入口。采购和销售订单同时显示记账状态与执行状态（未执行、部分执行、已完成），下游单据记账后，切回已打开的订单或列表会自动更新。
- 销售订单增加结算单位、收款到期日期、交货方式、客户要求和录单时间。前四项用于记录交易条件并带入销售出库单，录单时间由系统在保存时生成，供查验订单来源。这些字段依据共用表头和下游流程新增，原销售订单页面的对应字段未经核实。
- 销售订单和采购订单保存计划收付、费用及物流信息。订单本身不产生资金和费用流水。采购入库支持分账户付款、采购费用和物流发票资料。入库实际付款冲减应付，采购费用按期间费用处理，需计入存货成本时可使用采购费用分摊单。每种单据均可「保存并打印」，打印由浏览器完成。
- 「导入商品」打开本地文件选择器，读取 Excel（.xlsx）的第一个工作表。支持带表头的商品编号或条码、数量、可选单位和不含税单价，也兼容无表头的“商品编号或条码、数量、单价”。价格留空时按开单价格策略取价。一次最多 500 行，失败时显示行号，成功时显示导入行数。该入口填充当前单据；资料模块仍提供新增、修改、条码、商家编码、价格和属性六种商品资料导入模式。
- 顶部关闭、底部关闭及 Esc 均可退出表单。有未保存修改时弹出「确认退出?数据将不被保留」，可继续编辑或确认退出。
- 演示账套预置 `EXP-01 运输费用` 与 `LOG-01 青禾物流`，并补充可选择的报价单、销售订单和采购订单示例。正式账套使用资料模块已维护的科目和物流公司。资料为空时，弹框说明原因并提供新增入口。

## 期初建账

「期初建账」包含期初库存商品、期初应收应付、期初收支账户、期初资产负债表和开账，由管理员维护。

- 新账套处于「未开账」。业务单据可以保存草稿，提交审核、审核、记账和月结会提示「系统尚未开账」。
- 库存先选仓库，再直接修改期初数量和成本单价。保存采用覆盖方式，库存金额按数量乘成本单价计算，数量和金额立即进入库存查询。批次商品填写批号、生产日期。仓库表格覆盖同一商品时，以填写的批号重设该商品的期初批次。需保留多个批次或录入序列号时，使用「期初录入单（追加）」，经审核记账后生效。追加单可填写负数冲减，冲减后库存数量和金额须非负。
- 期初应收应付按往来单位录入应收、应付、预收、预付，支持客户或供应商筛选。同一单位应收与应付互斥，预收与预付互斥。未开账时也可在往来单位编辑页填写。期初余额进入往来余额及对账的期初汇总。
- 收支账户直接录入期初余额。资金账户列表同时显示期初余额和当前余额。
- 库存、应收、应付、预收、预付和现金银行自动汇总到资产负债表，其余资产、负债和权益科目可手工填写。科目在「资料 → 会计科目」维护。
- 库存和往来期初页面提供 Excel 模板下载及导入。按模板列顺序填写，导入先校验错误行，同一次跨仓导入原子提交，重复的仓库商品组合会被拒绝。
- 开账前必须处理所有未记账的期初录入单，并满足资产等于负债加所有者权益。可勾选将差额自动计入「实收资本」。建账日期不得晚于当天。开账后期初接口和录入单全部只读，业务日期不得早于建账日期。
- 只有没有任何已记账业务单据的账套才允许反开账。开账、反开账、期初保存均记录系统日志。已有业务单据的旧账套首次升级时自动标记为已开账。
- 数据重建清理期初和业务流水后，账套恢复未开账。原有备份仍按数据备份功能保存。

## 库存成本与报表核对

- 报溢、其他入库、报损、调拨及其他出库按所选仓库的当前库存成本取价。无库存时依次取参考成本价、采购价。多单位按换算率折算，记账时刷新成本并将实际库存流水金额回写到单据明细。
- 调拨、收付款及预收预付单的未结金额显示为「—」。收付款选择源单时仅列出有未结金额的已记账单据，并显示单据金额、已结金额和未结金额。
- 随单收付款在原业务单记账时生成，标记「随单结算」，成功提示列出生成的 FK/SK 单号。保存草稿时提示将在记账后生成。关联单据中可打开生成的收付款单，禁止独立删除或反审核。采购入库和销售出库原单可执行「反审核并撤销随单结算」，一并撤回库存、资金和往来分录。存在后续库存流水或独立结算单据时，会提示先处理后续单据。
- 利润表基于会计分录列出采购优惠收入、销售优惠支出、报溢收入和报损损失。日期范围内的「本期净利润」单独列示，「净利润」包含期初累计损益，与同截止日期资产负债表中的累计损益勾稽。资产负债表单列资产、负债和权益合计。
- 经营报告的采购、销售金额为扣除退货并计入换货差额后的净额，同时显示退货金额。对账明细首行显示与期初汇总合计一致的期初余额。

## 自定义打印模板

在「系统 → 打印模板中心」选择单据类型。每种单据都有系统默认模板，可新建多个模板、复制、重命名、设为默认、恢复系统布局及导入／导出 JSON。新建时弹窗输入名称，新建、复制、默认设置及导入后有完成提示，请求期间禁用操作按钮。默认模板不能删除，先设定其他默认模板再删除。保存使用版本校验，避免多人覆盖设计。

- 纸张支持 A4、A5、241×93mm、241×140mm 和自定义尺寸、方向及四边页边距。选择预设后立即更新宽高与方向，切换方向时交换宽高，再点击「应用纸张设置」。可单独勾选「适配布局」「保持字号」；取消适配时仅换纸、不缩放内容，不保持字号时正文至少 9pt、标题至少 12pt。连续纸可将页边距设为 5mm，再按实际纸张调整；适配后检查元素重叠及分页。区域和元素尺寸均以 mm 保存。
- 设计画布分为每页页眉、首页表头、表体、末页表尾和每页页脚。点击区域或选择左侧区域后，从字段库拖入字段，或双击字段插入；新增元素优先使用可见空白处，并在前一个元素旁错开放置，自动选中显示属性，固定文本直接进入编辑。可添加文本、线条、矩形、Logo／印章图片、单号条码、二维码、页码、打印时间和算术表达式，例如 `{含税金额}-{整单优惠}`。表达式仅支持字段、数字、加减乘除及括号，不执行 JavaScript。
- 拖动元素定位，属性中精确设置尺寸、字体、对齐、换行、小数位、千分位、人民币符号、日期格式及零值隐藏。Shift／Ctrl 多选，支持对齐、等距、图层、复制粘贴与撤销重做。方向键每次移动 0.2mm，Shift＋方向键移动 1mm；画布支持 Ctrl／Command＋C、V、Z、Y。
- 表体列可勾选、拖动排序、改标题、改列宽并设置数值格式。分页可指定每页行数或按表体高度自动计算，支持补空行、每页小计和末页合计；小计／合计占用行高，行数超过区域容量时拒绝保存。
- Logo 和底图支持 PNG、JPEG、WebP，单图不超过 1MB，单模板引用图片合计不超过 6MB。图片存入 SQLite，JSON 导出包含图片，可跨账套导入。套打底图仅在设计及预览显示，不输出到打印纸。
- 单据详情的「打印单据」、录入页「打印预览／保存并打印」使用同一模板渲染器。单据列表勾选后点击「批量打印」，可为不同单据类型分别选模板，各单据独立分页。真实数据预览支持翻页及缩放，单位累计欠款在预览／打印时重新查询。
- 「导出 PDF」打开浏览器打印窗口，请选择「另存为 PDF」；不包含服务器 PDF 转换服务。打印使用独立文档，隔离应用的打印隐藏规则；CSS `@page` 明确设置模板宽高与四边页边距，各分页及各单据连续输出，边距不会重复计入内容坐标。打印选择实际纸张尺寸、100% 缩放并关闭浏览器页眉页脚。Excel 导出使用所选模板的可见列、列顺序、每页小计、总计和单据字段，输出 `.xlsx`。
- 公司名称、地址、电话在「系统配置 → 公司信息」维护。模板可设置「未审核禁止打印」和「打印前自动保存」。未保存新单在关闭自动保存时需先保存；已有单据默认预览已保存的数据。
- 「职员权限」中可分别授权打印模板中心的「打印模板设计」和各单据的「单据打印／重复打印」。没有设计权限不显示设计入口，服务端也拒绝模板变更；重复打印需要额外授权。打印、PDF 提交记录次数和系统日志，模板可显示打印次数及「重打」标记。次数记录提交到浏览器打印窗口的请求，浏览器取消或打印机失败无法回传，不代表纸张实际输出次数；预览和 Excel 导出不增加打印次数。
- 模板保存在 `print_templates`，布局 `layout_json.version=1`，图片在 `print_assets`，打印记录在 `print_jobs`。原有数据库备份包含这三张表；数据重建清理打印记录，保留模板和图片。二维码采用 QR Model 2、L 级纠错，最多 106 个 UTF-8 字节；单号条码为 Code 39。
